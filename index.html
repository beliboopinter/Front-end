Meus Projetos

Detector de golpes

Esse projeto foi desenvolvido em uma das aulas da Residência Full Stack, junto com meu grupo. O objetivo desse projeto é análisar mensagens suspeitas de golpes e nos alertar, se é ou não uma mensagen segura. O sistema analisa a mensagem inserida e, a partir dessa análise, informa se ela é segura ou apresenta indícios de golpe. O projeto busca ajudar os usuários a reconhecer mensagens potencialmente perigosas e evitar possíveis fraudes.
